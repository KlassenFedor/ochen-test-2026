# Конструктор иллюстраций для Figma

Плагин собирает редактируемые композиции из десяти исходных предметов. Он подбирает предметы по заголовку или берёт их из списка, использует варианты L и S и сохраняет результат в SVG. Плагин работает в Figma Desktop через встроенный Plugin API. Сервер и MCP для запуска не нужны.

## Первый запуск

1. Откройте рабочий файл в Figma Desktop. На странице «Библиотека компонентов» должны быть секции «Библиотека · Компоненты» и «Демо · Плагин». Если секций ещё нет, один раз запустите [подготовку библиотеки](tools/prepare-library/README.md). Служебный плагин тоже включён в ZIP.
2. Для запуска из репозитория выполните сборку. В распакованном ZIP уже есть готовый каталог `dist/`.

   ```sh
   npm ci
   npm run build
   ```

3. Для первой локальной установки создайте development-плагин через `Plugins → Development → New plugin`. Возьмите выданный Figma `id` и добавьте его строкой верхнего уровня в `manifest.json` конструктора. У конструктора и служебного плагина разные ID. [Документация манифеста Figma](https://developers.figma.com/docs/plugins/manifest/)
4. Импортируйте манифест через `Plugins → Development → Import plugin from manifest`. Запустите «Конструктор иллюстраций» в рабочем файле. На вкладке «Новая композиция» введите `Книга, телефон` и нажмите «Создать композицию».

На вкладке «Редактирование» выделите кадр или предмет внутри него. В блоке «Цвета композиции» выберите готовую палитру или загрузите свою из JSON, затем нажмите «Перекрасить кадр». При создании новая композиция использует палитру со своей вкладки. Для смены роли выделите один предмет. Быстрый старт, примеры и частые вопросы доступны по кнопке «Помощь и инструкции» в панели.

## Разработка

```sh
npm test
npm run build
npm run package
```

`npm test` проверяет TypeScript, чистую логику, поведение адаптера на модели документа и правила подготовки библиотеки. Для проверки реальных узлов, цветов и экспорта используйте отдельный сценарий. [Визуальная проверка](Визуальная-проверка.md)

`npm run package` использует стандартный модуль `zipfile` из Python 3 и сохраняет архив в `artifacts/illustration-composer.zip`. Имена файлов с кириллицей помечаются как UTF-8. Если уже есть ID, добавьте его при упаковке командой `npm run package -- --plugin-id ВЫДАННЫЙ_ID`.

Мастера индексируются по именам наборов и вариантам `Size`, `Role` и `Scheme`. Эталонные габариты и цветовые привязки плагин читает с мастеров открытого документа. Сцена хранит настройки в `pluginData`, а позиции и порядок предметов берутся с холста. Штатные палитры читаются из переменных библиотеки с исходной точностью RGB.

Размеры кадров 1080 × 1080, 1200 × 630 и 900 × 1200 выбраны для первой версии. Размеры и точки привязки можно уточнить после просмотра реальных композиций. [Настройки форматов](data/layouts.json)
