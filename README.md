# Конструктор иллюстраций для Figma

Плагин собирает редактируемые векторные композиции из десяти предметов. Их можно выбрать по названию или подобрать по смыслу заголовка. Есть три формата кадра, два уровня детализации и три готовые палитры.

## Установка из ZIP

1. Распакуйте `illustration-composer.zip` в отдельную папку.
2. Откройте новый пустой файл **Figma Design** в **Figma Desktop**.
3. Выберите **Plugins → Development → Import plugin from manifest** и укажите `manifest.json` из распакованной папки.
4. Запустите **«Конструктор иллюстраций»** из меню **Plugins → Development**.

В архиве один плагин со встроенной библиотекой. При первой сборке он установит в текущий файл 46 мастер-компонентов и три палитры. Для запуска из ZIP достаточно Figma Desktop.

## Быстрая проверка

1. На вкладке **«Новая композиция»** введите `Книга, телефон`, выберите квадрат, детализацию **L** и нажмите **«Создать композицию»**. Кадр появится в секции **«Демо · Плагин»**.
2. Передвиньте телефон на холсте. Выделите его и во вкладке **«Редактирование»** нажмите **«Сделать фоновым»**. Проверьте, что изменились роль и вид предмета, а его положение сохранилось.
3. Выберите другую палитру и нажмите **«Перекрасить кадр»**. Через **«Создать другую раскладку»** можно получить отдельный вариант рядом с исходным.
4. Нажмите **«Экспорт SVG»** и перетащите скачанный SVG обратно на холст. Раскройте кадр в **Layers** и проверьте, что видимые предметы можно выделять отдельно. Например, группы книги и телефона называются `Kniga` и `Telefon`.

Для подбора по смыслу попробуйте заголовок `Учиться в дороге`. Плагин предложит книгу и наушники. Подсказки по работе доступны в окне **«Помощь и инструкции»**.

## Своя палитра

В архиве есть пример `data/example-palette.json`. Палитра содержит `version: 1`, название `name` и два массива с четырьмя цветами формата `#RRGGBB` в каждом. Массив `background` задаёт оттенки фона, а `object` — главных предметов.

Загрузите файл при создании композиции или выберите **«Палитра из JSON»** на вкладке редактирования и нажмите **«Перекрасить кадр»**.

## Сборка из репозитория

Понадобятся Node.js 20+ и Python 3. Запустите команды в корне проекта.

```sh
npm ci
npm test
npm run package -- --portable
```

Архив появится по пути `artifacts/illustration-composer.zip`. Команда `npm run build` отдельно собирает файлы плагина в `dist/`, если вы хотите запустить плагин напрямую из репозитория через его `manifest.json`.
