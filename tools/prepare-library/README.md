# Подготовка библиотеки иллюстраций

Подготовка доступна в «Конструкторе иллюстраций». Установка и запуск описаны в [основном README](../../README.md#первый-запуск).

В подготовленном демофайле плагин сразу открывает форму сборки. Если в файле задания есть только исходники, на вкладке «Новая композиция» будет кнопка **«Подготовить библиотеку»**. Она создаёт 40 вариантов предметов, 6 фонов, переменные палитр, обзор и секцию «Демо · Плагин». При наличии мастеров команда восстанавливает отсутствующую демосекцию.

Для проверки геометрии, цветовых привязок и SVG в исходном файле откройте **«Помощь и инструкции» → «Как проверить библиотеку и скачать отчёт?»**. После проверки появится ссылка **«Скачать отчёт о библиотеке»**. Отчёт `figma-library.json` содержит каталог компонентов, исходные RGB, привязки и результаты проверки SVG.

Неоднозначные назначения выводятся с указанием мастера, слоя и возможных позиций палитры. При ошибке, отмене или закрытии окна удаляются ресурсы текущего незавершённого запуска.

ID слоёв в плане подготовки служат для проверки оригиналов. Сборка композиций в готовом файле и его полных копиях использует имена наборов и свойства вариантов, поэтому ей достаточно существующих мастеров, палитр и демосекции.
