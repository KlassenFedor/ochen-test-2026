# Подготовка библиотеки Figma

Служебный плагин только для подготовки исходников, не реализация конструктора композиций. Работает через встроенный Plugin API, без MCP и сети. Подготовлен после исчерпания лимита интеграции; **в Figma пока не запускался**.

## Запуск

1. В Figma Desktop создать локальный плагин через Plugins → Development → New plugin и взять выданный `id` из его манифеста. ID назначает Figma; в проекте он не выдуман. См. [описание манифеста](https://developers.figma.com/docs/plugins/manifest/).
2. При запуске из репозитория выполнить `node tools/prepare-library/build.mjs --plugin-id ВЫДАННЫЙ_ID`. Зависимости не нужны. При запуске из распакованного ZIP код уже собран. Добавьте выданный ID строкой верхнего уровня в `tools/prepare-library/manifest.json`.
3. В Figma Desktop открыть рабочий файл `OQnymDXpbDHoABKg8ks9R7`.
4. Через Plugins → Development → Import plugin from manifest выбрать `tools/prepare-library/manifest.json` и запустить плагин.
5. После проверки скачать `figma-library.json` из панели. Он содержит каталог с устойчивыми ключами, три палитры, привязки каналов к позициям, точные исходные RGB и результаты проверки SVG.

Локальная проверка логики: `node tools/prepare-library/check.mjs`. Сборка уже подготовлена в `build/code.js`, но для регистрации в Figma нужен выданный платформой ID.

## Что делает

- Проверяет все источники до изменений. ID из `library-plan.json` используются только для этой разовой подготовки, не для поиска компонентов будущим конструктором.
- Создаёт две секции на существующей странице «Библиотека компонентов», сохраняя исходные листы и созданные ранее композиции.
- Создаёт 10 наборов вариантов: `book`, `phone`, `puzzle`, `coin`, `headphones`, `lamp`, `bouquet`, `wallet`, `folder`, `pen`. У каждого — `Size=large/small` и `Role=main/background`.
- Создаёт набор `background` с шестью вариантами `Size=large/small` × `Scheme=violet/peach/turquoise`.
- Сохраняет геометрию и габариты. Две отдельные детали L-книги включаются в соответствующие компоненты.
- Создаёт переменные исходных цветов и семантические привязки. Каждая палитра хранится в своей коллекции с одним режимом, чтобы не требовать платных режимов или новых страниц.
- Оттенки вне основных восьми позиций сохраняет как `detail/*`. Это в том числе детали монеты и букета, белые элементы фона и нейтральные цвета скрытых исходных слоёв. Они явно помечены как постоянные, не сопоставляются с палитрой по догадке.
- Создаёт обзор с экземплярами всех 46 вариантов; мастера находятся отдельно от обзора.
- Сверяет геометрию клонов с оригиналами, проверяет привязки и экспортирует каждый вариант для поиска растровых `<image>`.
- При повторном запуске проверяет существующую библиотеку и выгружает каталог без дублирования. Неполную или изменённую структуру не перезаписывает молча.

Созданные в неудачном первом запуске секции и новые коллекции откатываются. Исходные объекты не изменяются. Проверка SVG выполняется программно; визуальный контроль и повторный импорт SVG в Figma остаются обязательными после запуска.
